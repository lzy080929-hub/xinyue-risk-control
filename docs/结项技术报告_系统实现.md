# 信跃大学生金融素养平台与模拟信贷申请系统技术报告

版本日期：2026年10月26日。本报告说明已经实现的系统及其验证范围，可作为结项报告中的系统成果附件。项目成员、指导教师、正式采样情况与学校表格信息由项目组根据真实情况另行填写。

## 一、建设目标

系统由两个明确分开的部分组成：面向公众的金融素养学习平台，以及经知情同意后开展数据采集的科研模拟信贷申请。学习平台提供金融素养测评、校园金融科普和本地学习工具，帮助学生理解预算、借贷成本、常见骗局与风险；研究部分将模拟申请与29题还款看法问卷连接起来，采集申请信息、量表答案及必要的操作事件，支持研究人员查看过程、核对记录和导出分析材料。

建设重点是学习反馈与研究数据边界清楚、最终保存可靠、过程可追溯，以及申请行为与量表阶段的区分。

## 二、实现方案

系统沿用Flask、HTML、CSS及原生JavaScript。后端使用SQLAlchemy管理参与会话、草稿、行为批次、行为汇总、提交快照和逐题答案，以迁移脚本维护数据库结构。本地验证采用独立SQLite数据库；正式服务配置要求使用持久PostgreSQL，配置缺失时拒绝启动。

公共学习平台与模拟申请由同一Flask应用提供，但页面、脚本、内容版本和存储路径分开。学习平台不创建研究参与会话、不加载行为采集脚本、不调用研究API，也不建立服务端学习账户。研究申请保留原有8页流程：知情同意、基础信息、收入与总负债、贷款需求、利率确认、信息核对以及上下两页量表；界面采用灰色背景、白色表单、深蓝色页头与流程导航，保持上一页和下一页方式，面向手机和电脑使用。

## 三、公共学习平台

平台首页为`/`，研究申请移至`/apply`；旧测试与招募链接`/?test=1`、`/?source=...`会保留查询参数并转到申请页。平台版本为`platform-v1`，学习测评为`literacy-learning-v1`。

| 模块 | 实际功能 |
| --- | --- |
| 平台首页 | 以“测一测—学一学—练一练”组织测评、科普和申请体验入口；展示示例预算与借贷成本，不给出个性化授信结论 |
| 学习测评 | 16道平台自编客观题，预算、借贷、安全、风险4个主题各4题；每题可选“暂不确定”；提交前不显示解释 |
| 测评反馈 | 提交后显示答对题数、正确率（答对÷16）、完成度、主题表现、建议复习主题与逐题解释；未作答和“暂不确定”不计为正确 |
| 知识科普 | 12篇短主题，按“校园情境—概念—小算例—行动提示—来源与日期”组织，不推荐具体金融产品 |
| 学习工具 | 借贷成本试算、生活费预算和反诈情境判断；计算与选择均只在浏览器内完成 |
| 我的学习 | 显示最近一次测评摘要、已读文章和工具使用状态，可清除当前浏览器的学习记录 |

学习测评不声称经过心理测量学认证、等同OECD官方题库或可用于信用评价。平台只报告本次答题表现，不生成个人违约概率、信用等级或授信建议。

## 四、研究申请

| 模块 | 实际功能 |
| --- | --- |
| 参与与同意 | 同意后创建随机参与编号；不要求真实姓名或证件；测试记录独立标识 |
| 草稿保存 | 输入后自动保存，同标签页刷新恢复；未作答与数值0分别保存 |
| 行为采集 | 页面可见、隐藏、字段聚焦、输入、删除、粘贴、重访、返回与指定字段切换等事件；不记录输入过程正文或剪贴板内容 |
| 过程同步 | 约每5秒及切页时批量上传；按批次编号去重；失败保留待传队列并重试 |
| 最终保存 | 等待服务器回执；提交与逐题答案事务保存；重复请求返回同一提交结果 |
| 量表计分 | 保存29题原始答案；7道反向题按8减原分；分开计算ATR、SN、PBC、LRI总分、均分及有效题数 |
| 研究后台 | 管理员登录、约5秒刷新、记录详情、正式/测试、状态、日期、来源与版本筛选 |
| 数据导出 | 每次参与一行的分析CSV与申请阶段事件明细；默认选择正式已提交记录；中文Excel编码与公式前缀处理 |
| 版本管理 | 协议、量表、表单与行为版本保留；独立记录新界面版本，跨界面恢复有质量标记 |
| 部署准备 | Render配置、生产启动迁移、健康检查、仅含允许文件的发布包、只读公网检查工具 |

## 五、数据质量与研究边界

系统分别记录问卷提交状态与行为完整性。收到最终保存回执表示申请及量表已保存；行为批次齐全还需要核对批次数、事件数与连续序号。完整性标记不等于数据真实性，也不证明手机关闭前所有行为均被观察。

申请阶段的过程变量与量表阶段分开。字段聚焦时长不是注意力真值，修改或粘贴不能直接解释为不诚信。LRI反映自报还款意向，不是真实违约结果；四个构念分开计分。系统未根据量表或操作行为生成个人信用等级。

学习数据与研究工作严格分开：

- 测评摘要、已读主题和工具使用状态只保存在当前浏览器的`xinyue.learning.v1`，不包含逐题选择、计算器输入、申请字段、量表答案或行为事件。
- 学习页面不调用研究API，不创建参与编号，不写研究数据库，也不进入分析CSV或申请阶段行为明细。
- 本轮没有新增研究数据库迁移，不改变实验、表单、量表、行为或界面版本，不向历史记录补写学习结果。
- 更换设备、无痕窗口或清理浏览器数据会丢失学习记录；系统不提供账号、跨设备同步或服务端找回。

原JSON、CSV及历史数据库记录保留。总负债与早期表单中的每月还款额保持不同字段。测试记录不得计入正式样本；不同界面或协议版本需核验后再开展分析。RRT本轮不启用。

## 六、验证与证据

2026年10月26日的最终检查中，69项Python/API/迁移测试全部通过。真实Chrome验证使用独立迁移的SQLite数据库，检查了平台首页、测评、科普、工具和“我的学习”在320、360、390和1440宽度无横向溢出、测评计分与“暂不确定”处理、重试、本地摘要结构、阅读标记、工具计算结果、清除学习记录、学习页零研究API请求，以及旧申请链接跳转后仍保留8页流程。详细命令、报告路径与限制见《VERIFICATION.md》。

研究申请的既有浏览器回归仍通过：17个行为批次、四个分量表计分、后台与CSV流程正常，无JavaScript异常。自动化检查使用测试数据库，截图来自运行中的测试页面，不是正式样本。

系统已在既有Render网址实际发布8页研究申请版本`8067c0d`。公网Chrome移动视口已完成8页及29题，验证保存回执、重复提交、后台访问保护，以及服务实例更换后同一TEST回执保留。**本轮公共学习平台代码尚未发布到该公网服务**；本地页面、测试报告或部署包不能替代实际发布验收。免费PostgreSQL当前为试运行资源，于2026年11月25日到期；长期保留需另行安排。实体手机/微信、研究者密码登录后的CSV下载及PostgreSQL完整备份恢复，仍须以各环境的实际结果补充。
