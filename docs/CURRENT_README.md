## 功能

### 公共学习平台

1. 首页按“测一测—学一学—练一练”组织三个模块，并提供精选科普和工具入口。
2. 学习测评共16道平台自编客观题，4个主题各4题；可选择“暂不确定”。提交后才显示解释，正确率按答对题数÷16计算，同时报告完成度，未作答和“暂不确定”都不计为正确。
3. 12篇科普采用“校园情境—概念—小算例—行动提示—来源与日期”的结构，不推荐具体金融产品。
4. 借贷成本试算、生活费预算和反诈情境判断均只在浏览器内计算，不发送输入。
5. “我的学习”只汇总本地测评摘要、已读主题和工具使用状态，不需要账号，不跨设备同步。

### 研究申请

1. 知情同意后创建参与会话；同意前不发送研究数据。
2. 原有8页流程：同意、申请人信息、收入与总负债、贷款需求、利率、确认、量表上、量表下。
3. 字段聚焦、页面可见时长、输入、删除、输入后删除、粘贴、返回、跳填及收入与负债字段切换。只记录事件与时长，不记录按键正文、粘贴内容或屏幕录像。
4. 约每5秒及切页时批量同步。断网时在当前标签页保留待传批次，恢复后重试；重复批次不会重复累计。
5. 草稿自动保存、同标签页刷新恢复；最终提交前上传剩余批次，收到服务器保存回执才显示成功。手机被强制关闭等情形仍可能丢失最近未同步片段，后台保留完整状态和恢复标识。
6. 原始29题答案与四个分量表计分由同一事务保存。7道反向题按8减原分转换；分量表分开计分，不生成个人信用评分或真实违约标签。
7. 需要登录的后台每5秒刷新，支持正式/测试、状态、日期、来源与版本筛选；导出分析CSV及申请阶段行为明细。
8. 数据、口令和备份不放入静态目录；正式环境要求持久PostgreSQL，缺少配置拒绝启动。

原来的JSON、CSV、阶段一/二数据库记录与量表题项不被自动改写或删除。原来“总负债”与阶段二的“每月还款额”保持不同字段。新增实验版本为`xinyue-original-v3`。本轮学习平台不改变研究协议、数据库结构或量表计分，因此不需要数据库迁移，也不把学习数据补写进历史参与记录。

## 本机启动

不熟悉命令行时，双击项目根目录的`启动信跃网页.cmd`。它会启动本机程序，页面就绪后自动打开浏览器。使用时保持启动窗口打开；关闭程序或重启电脑后需再次启动。这个入口只打开本机测试页面，不能转发给其他人。

已有`.venv`与依赖时，在PowerShell运行：

```powershell
Set-Location E:\lzy\Documents\credit_loan
.\start_local.ps1
```

启动脚本会先备份已有本机数据库、执行迁移，再启动服务。平台首页为 <http://127.0.0.1:5000/>，学习测评、科普、工具与“我的学习”从首页进入；研究申请为 <http://127.0.0.1:5000/apply>，本机测试申请为 <http://127.0.0.1:5000/apply?test=1>，后台为 <http://127.0.0.1:5000/admin/login>。旧的`/?test=1`与带`source`参数的链接仍会保留参数转到`/apply`。

如果尚未配置管理员，从本机后台登录页点击“首次设置本机管理员”，自行设置用户名和至少12位密码。密码只以哈希写入被忽略的`.env`。该设置页仅对尚未配置管理员的本机开发环境开放，在生产环境关闭。配置过管理员后直接登录；请勿把密码贴进聊天或公开仓库。

首次准备环境：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
```

如终端不允许执行PowerShell脚本，可以顺序运行：

```powershell
.\.venv\Scripts\python.exe scripts/backup_local.py
.\.venv\Scripts\python.exe -m flask --app app db upgrade
.\.venv\Scripts\python.exe app.py
```

按Ctrl+C停止自己在终端启动的服务。`127.0.0.1`仅供本机，不能转发给其他同学。

## 研究者使用

- 测试入口产生`TEST-`记录，不计入正式样本。正式和测试记录均可在后台明确筛选。
- 链接可带来源标签，例如`/apply?source=class_a`；旧的`/?source=class_a`仍兼容并转到申请页。仅允许字母、数字、下划线和连字符，不放姓名、手机号等信息。
- 学习平台的测评、阅读和工具记录只在浏览器本地，不创建参与编号，也不进入后台筛选或CSV。
- 后台统计的是参与会话数量，不是保证去重的人数。
- CSV默认导出已提交的正式记录；测试和未完成数据必须主动选择。日期筛选按北京时间计算。
- 分析CSV包含原始申请字段、29题原始分、ATR/SN/PBC/LRI分数、申请行为特征、版本、缺失值与质量标识。申请行为明细不混入量表阶段事件。
- `complete`表示服务器收到的批次与最终声明一致，不表示行为能证明诚信，也不保证手机强制关闭前没有未观察的片段。旧记录没有完整性声明时不追认完整。
- 收入和总负债自愿作答，空值与0区分。总负债/月收入比自动计算，可能超过100%；收入为0或缺失时留空。

## 实现边界

- 学习平台内容为平台自编，不是经过心理测量学认证的标准化测验，也不等同OECD官方题库或分数；正确率不代表信用水平、还款能力或未来金融行为。
- 学习测评只报告个人在本页的答对比例、完成度和主题表现；不生成个人违约概率、信用等级或授信建议，不把学习结果写入研究申请。
- 学习记录仅在当前浏览器，换设备、无痕窗口或清理浏览器数据后会丢失；“我的学习”不提供账号、跨设备同步或服务端找回。
- RRT为原计划中的可选后续模块，当前不启用。不能用群体逾期比例给个人贴标签。
- 暂不接入在线机器学习预测、真实征信或真实放贷。公开数据模型结果不等于自采行为的预测效果。
- PostgreSQL实库、生产服务更新及真实手机/微信结果只能在实际完成后标记通过。
- 正式采集前固定题项、字段含义、页面顺序与指标版本；试填与不同版本数据分开分析。
