# 固定条款、本人承诺与RRT

版本日期：2026年10月27日。适用于新申请`xinyue-fixedrate-v4`，正式上线状态以README和VERIFICATION为准。

## 申请流程

仍为8页：知情同意、申请人信息、收入与总负债、贷款需求、条款确认、信息与本人承诺、量表上、量表下。29题原文、反向题和计分版本保持不变。提交并取得主申请保存回执之后，另有自愿参加的独立随机应答调查。

顶部“返回平台首页”直接回到学习平台。已同意且开始填写的草稿在同标签页保留；首页恢复横幅支持v3/v4。旧v3标签页刷新后通过`/apply/legacy`及冻结模板、脚本继续原条件，不补写承诺或改动其利率。

## 平台展示条款

新申请取消三档利率选择，参考商业银行展示具体条款、申请人确认的流程。服务器创建会话时固定并保存`terms_snapshot`：名义年利率6.00%，按月等额本息，无额外费用。它是统一研究情境，不是银行真实报价，也不按收入、负债、量表或行为定价。此数值不代表当前市场平均利率。

第5页展示名义年利率、月供、总还款、总利息与按月复利折算的有效年化率。月利率r=名义年利率/12，月供A=P×r/[1−(1+r)^−n]；金额四舍五入到分，末期可能有取整调整。10,000元、12个月的示例月供860.66元，总利息327.97元，有效年化率6.17%。服务器拒绝与会话条款不一致的客户端利率，也不允许换用旧表单绕过承诺。

真实银行的具体条件以其审批、展示信息与合同为准。参考[工行融e借合同](https://media.icbc.com.cn/agreement/939007358095667201.html)和[工行贷款服务说明](https://mgf.trade.icbc.com.cn/mobile/sfpmWholeSaleProd/sfpmSubjectMatter.jhtml?appEdition=1&prodId=B000615605)。本系统未连接银行审批系统。

## 第6页本人承诺

固定文本：本人已阅读本次申请说明和展示条款，确认以上信息为本人自主填写。

参与者可点击复制再粘贴，也可长按复制或手动输入。浏览器核对固定文本后勾选本人确认。自动复制不支持时保留手动方式。不要求真实姓名或还款保证，不把这一步当成真实贷款合同签署。

承诺框没有上传字段名，正文不进入草稿、最终提交、行为事件或浏览器暂存。只保存`pledge_version`和`pledge_confirmed`，以及独立`pledge`阶段的复制、粘贴、输入、确认事件次数。承诺产生的粘贴不计入普通申请字段的粘贴特征。确认后的刷新按已保存状态恢复固定公示文本；尚未确认的承诺输入不暂存。其他申请内容修改后须重新确认。

第6页时长仍包含承诺操作，不应把新版与旧版页时长直接解释成同一实验条件。统一增加承诺不是随机对照实验，不能把新旧结果差异直接归因为承诺。

## 主问卷之后的RRT

主申请和29题先独立保存。调查先解释规则，参与者勾选自愿同意后，浏览器以可靠随机源私下抽题：

- 50%回答过去12个月是否在还款日（含事先约定宽限期）结束后仍未付清个人信用借款当期必须偿还的金额。
- 50%回答一个独立公平随机结果是否为正面。

本调查中，信用卡按账单标明的最低还款额，分期借款按约定当期应还金额判断。没有到期借款经历按否回答。因此总体是所有调查对象，不是只在借款人中计算的违约率。

两次抽取只在浏览器内存与当前界面使用，不上传分支、随机结果、种子或过程时长，不写URL或持久存储，不运行研究行为追踪。刷新不会恢复私下抽签；网络失败时保留当前抽签和选择重试，不重新抽签。

服务器用独立凭证防止同一次参与重复计数：`rrt_invitations`只存参与资格、凭证哈希、方案版本与兑付状态，没有回答或回答编号；`rrt_responses`只存随机响应编号、混合是/否/同意后跳过、版本、测试标记及按日批次，没有参与编号、凭证、精确作答时间。凭证和网络日志仍可能提供关联线索，不承诺绝对不可关联。单人回答不加入申请CSV。

未勾选同意而“暂不参加”时不创建调查凭证、不保存RRT回答；后台跳过数仅统计同意后主动跳过的人。RRT失败不回滚主申请。网络重试及并发兑付通过事务保证至多新增一条响应；重复请求只返回已记录确认，不返回个人答案。

## 群体统计

研究后台增加“RRT群体统计”，正式组和测试组分开。方案`rrt-uq50-v1`中混合是比例λ=0.5P+0.25，因此原始估计P̂=2λ−0.5。对λ计算95% Wilson区间再线性变换，保留超出0—100%的原始点估计与区间，另列限制到0—100%的辅助点估计。小样本、选择性跳过和不遵循随机规则会限制解释，不能将结果当作个人逾期标签。

方法参考：[Greenberg等，无关问题随机应答模型，1969](https://www.tandfonline.com/doi/abs/10.1080/01621459.1969.10500991)。
