# 现在怎样使用信跃

网站已经在Render运行，不需要你的电脑开机，也不需要每次启动本机程序。

**当前公网仍运行2026年10月26日发布的8页申请版本（提交`8067c0d`），本轮新增学习平台尚未发布。** 发布并验收后，首页会变成学习平台，研究申请移到`/apply`，旧测试链接仍兼容；届时需要同步更新本篇入口。

当前公网入口：

- 发给参与者的入口：https://xinyue-risk-control.onrender.com/
- 自己试填或结项演示：https://xinyue-risk-control.onrender.com/?test=1
- 研究者后台：https://xinyue-risk-control.onrender.com/admin/login

后台使用你在本机设置的用户名和密码。测试入口会标记为TEST，不能计入正式样本。请先用手机移动网络和微信试开测试链接，再组织正式填写。

免费版服务久未访问会休眠，重新打开可能需要等待约一分钟。[Render官方说明](https://render.com/docs/free#spinning-down-on-idle)

当前免费数据库于2026年11月25日16:58（北京时间）到期。到期前需要导出、迁移或升级，不作为长期研究档案保存方案。

只有查看本机版本时才需要双击项目文件夹的“启动信跃网页.cmd”，使用时保持启动窗口打开。本机新版平台首页为<http://127.0.0.1:5000/>，研究申请为<http://127.0.0.1:5000/apply>；启动入口当前仍会打开测试申请。本机127.0.0.1地址不能发给别人使用。
