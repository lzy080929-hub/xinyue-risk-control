# 现在怎样使用信跃

网站已经在Render运行，不需要你的电脑开机，也不需要每次启动本机程序。

**金融素养平台已于2026年10月27日上线。** 首页提供测评、知识科普、学习工具和申请体验；原来的8页申请与数据采集继续保留。

新版申请已增加固定6.00%名义年利率及成本、本人承诺、主问卷保存后的自愿RRT与顶部返回首页按钮。若仍看到利率三选一，说明正在恢复旧草稿；点击页面的“另开新版申请”即可，旧草稿会保留。

当前公网入口：

- 平台首页：[打开信跃](https://xinyue-risk-control.onrender.com/)
- 直接发给研究参与者：[申请入口](https://xinyue-risk-control.onrender.com/apply)
- 自己试填或结项演示：[测试申请](https://xinyue-risk-control.onrender.com/apply?test=1)
- 研究者后台：[后台登录](https://xinyue-risk-control.onrender.com/admin/login)

后台使用你在本机设置的用户名和密码。旧`/?test=1`及带来源标签的链接仍兼容。测试入口会标记为TEST，不能计入正式样本。请先用手机移动网络和微信试开测试链接，再组织正式填写。学习测评与阅读记录仅保存在访客自己的浏览器中；经同意后的申请、量表和行为数据才进入研究后台。

免费版服务久未访问会休眠，重新打开可能需要等待约一分钟。[Render官方说明](https://render.com/docs/free#spinning-down-on-idle)

当前免费数据库于2026年11月25日16:58（北京时间）到期。到期前需要导出、迁移或升级，不作为长期研究档案保存方案。
